# BTK Akademi Otomatik Kurs Botu

**BTK Akademi Otomatik Kurs Botu**, BTK Akademi platformundaki kursları otomatik olarak tamamlamaya yardımcı olmak amacıyla hazırlanmış basit bir JavaScript botudur.

> 📌 Bu proje yalnızca **öğrenme ve deneme amaçlıdır**. Her türlü kullanım sorumluluğu kullanıcıya aittir.

---

## 🚀 Özellikler

- BTK Akademi kurslarını otomatik olarak ilerletmeye yardımcı olur.
- JavaScript ile yazılmıştır.
- Tarayıcı konsolu üzerinden çalışır, ek kurulum gerektirmez.

---

## 📋 Gereksinimler

Bu projeyi kullanabilmek için:

- Güncel bir web tarayıcı (Chrome, Edge, Firefox vb.)
- Aktif bir **BTK Akademi hesabı**
- BTK Akademi üzerinde tamamlamak istediğiniz bir kurs

---

## 📦 Kullanım

1. Bu repodaki **`console.js`** dosyasının içeriğini kopyalayın.
2. **btkakademi.gov.tr** sitesine girin ve tamamlamak istediğiniz kursa katılın.
3. Kursta herhangi bir videoyu oynatın.
4. Sayfada **sağ tık → İncele** seçeneğine tıklayın.
5. Açılan geliştirici araçlarında **Console (Konsol)** sekmesine geçin.
6. Kopyaladığınız `console.js` kodunu konsola yapıştırıp **Enter** tuşuna basın.
7. Bot otomatik olarak çalışmaya başlayacaktır.
